Privacy Policy

Data controller: James Rowson. This secure messaging site is part of Jahosi.co.uk.

Purpose

This site provides private messaging between invited account holders. It also includes safeguarding and moderation functions: Adult accounts are view-only observer accounts that can review conversations and report messages for safety, without appearing present, sending messages, or changing read receipts.

Data Stored

The service stores account details, display names, optional email addresses, password hashes, security status, user preferences, messages, uploaded media paths, reports, reactions, view-once view records for basic users, and basic users' last-seen timestamps. If push notifications are enabled for a basic user, the service stores that user's browser push subscription.

Safeguarding And Adult Accounts

Adult users can view posts and media, including view-once media, for safeguarding. Adult viewing does not write a view-once record, update presence, or affect read receipts. Only basic user activity is used for read receipts and online/last-seen status. If an Adult reports a message, the report is stored against that Adult account and can be reviewed by an administrator.

Storage And Longevity

Messages and message metadata are stored in the encrypted database until they are removed by an administrator or the service operator. Deleted messages are soft-deleted: they stop appearing in chat but their content and media path are retained for audit. Uploaded images and videos are stored in the protected uploads directory and are not automatically deleted by the app. Reports and review notes are retained for moderation/audit unless removed by the service operator.

Login sessions expire after 7 days. One-time passcodes for two-factor login or invitations expire after 10 minutes, and expired session/passcode records are periodically cleaned up. Basic users' last-seen timestamps, view-once view records, preferences, and any push subscriptions remain stored until changed, cleared, or the account/data is removed. Disabled accounts are retained so message history remains attributable.

Security

The application stores its main database using SQLCipher encryption. Uploaded media is served only to authenticated sessions. Passwords are stored as salted hashes, not plaintext. If Cloudflare Turnstile is configured, login challenge data is sent to Cloudflare for bot protection. Email addresses may be used to send invite or two-factor authentication codes through the configured mail service.

Sharing

Message content is not sold, used for advertising, or sent to analytics services by this application. Access is limited to authenticated users according to their role, Adult safeguarding observers, administrators, and the service operator where needed to run, secure, back up, or moderate the service.

Your Choices

Users can change their password and, where available, adjust display preferences. Requests about access, correction, deletion, or safeguarding records should be directed to James Rowson through Jahosi.co.uk. Some information may need to be retained where required for safety, security, audit, or safeguarding purposes.
